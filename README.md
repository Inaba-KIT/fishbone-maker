# フィッシュボーン図メーカー

ブラウザだけで使えるフィッシュボーン図（特性要因図）の作成ツールです。
サーバーやインストールは不要で、`index.html` 1つで動きます。
おためし　https://inaba-kit.github.io/fishbone-maker/

---

## 使い方

### 1. 文字を入れる
- 図の中の文字（右の「問題（結果）」、四角の「要因」、線の上の「クリックして入力」）をクリックすると、その場で入力できます。
- **Enter** で確定します。小要因を入力しているときは、Enter を押すと次の小要因の入力に移ります。続けて書いていけます。
- 入力をやめるときは、**何も書かずに Enter** を押すか、**Esc** を押します。
- 長い文字は、枠に収まるように自動で小さくなります。

### 2. 骨を増やす・減らす
| ボタン | 場所 | すること |
|---|---|---|
| ⊕ | 要因の四角の近く（左側） | 小要因を1本増やす（最大6本） |
| ⊖ | 小要因の線の左下 | その小要因を消す |
| ⊗ | 要因の四角の右上 | その要因を小要因ごと消す（確認が出ます） |
| ＋ 大骨を追加 | 問題の下 | 要因を1本増やす（最大10本） |

要因1・2が問題のすぐ左に来て、3・4、5・6…と尾びれ側に増えていきます。

### 3. 見やすくする
- 右下の **−／＋** で縮小・拡大、**⛶** で図全体を画面に合わせます。
- **Ctrl ＋ マウスホイール** でも拡大・縮小できます。
- 拡大しているときは、図の何もないところを**ドラッグ**すると図を動かせます。

### スマホで使うとき
- 線の上の点線の枠（「タップして入力」）をタップすると、キーボードが出て入力できます。
- 1本指でなぞると図が動き、2本指でつまむ・広げると縮小・拡大できます。
- 横長の図なので、スマホを横向きにすると広く見えます。

### 4. 保存ボタンとメニュー（右上）
**保存ボタン（フロッピーディスクの絵）** を押すと、次の項目が出ます。保存していない変更があるときは、ボタンの右上にオレンジの点が付きます。
- **ファイルに保存**：作業の途中の内容をファイル（.json）に保存します。
- **ファイルを開く**：保存したファイルを開いて、続きから作業します。別のPCでも開けます。
- **画像にエクスポート（PNG）**：スライドや資料に貼るための画像を保存します。
- **PDFにエクスポート（A4横）**：印刷や提出用のPDFを保存します。
- **PowerPointにエクスポート（.pptx）**：16:9のスライド1枚に、PowerPointの図形で書き出します。文字の書き換えやTeamsでの共同編集ができ、大骨ごとにグループになっています。

**メニュー** を押すと、次の項目が出ます。
- **配色**：ネイビー・グリーン・オレンジ・モノクロ（白黒印刷向け）から選べます。
- **使っていない骨を消す**：何も書いていない小要因と、名前も小要因も空の要因を、画面の図から消します（確認が出ます）。要因は2本、小要因は要因1本につき1本は残ります。
- **リセット**：全部消して最初に戻します（確認が出ます）。
- **使い方（PDF）**：1枚にまとめた使い方（`使い方.pdf`）を開きます。

書き出した画像・PDF・PowerPointには、ボタンや「クリックして入力」の案内は入りません。

保存・エクスポートのときは、ファイル名を決める画面が出ます。一度入れた名前は、ページを開いている間は次の保存でも最初から入っています（例：「3班_遅刻の原因」）。

エクスポートの画面には、毎回 **「使っていない骨を消して書き出す」** のチェックが出ます（最初はチェックが入っています）。チェックを入れたままにすると、空の小要因と、名前も小要因も空の要因を除いて書き出します（画面の図はそのまま残ります）。空の骨も残したいときはチェックを外します。

### 5. 知っておくと安心なこと
- 入力した内容は、使っているブラウザの中に**自動で保存**されます。ただし、ブラウザの履歴やキャッシュを消したとき、学校などの共用PCでログアウトしたとき、別のブラウザで開いたときなどは、**消えたり見えなくなったりすることがあります**。
- そのため、作業を終えるときは**毎回「ファイルに保存」**をしておきましょう。続きは、保存ボタンの「ファイルを開く」からできます（別のPCでも開けます）。
- 「ファイルに保存」していない変更があるままページを閉じたり再読み込みしたりすると、ブラウザの確認（「このサイトを離れますか？」など）が出ます。
- 入力した内容がインターネット上に送られることはありません。
